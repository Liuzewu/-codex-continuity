# 只读维护审计

把下面的提示词用于系统、应用或项目整理前的检查。它只授权读取；后续修改应按实际范围另行判断。

```text
请对 <目标设备／应用／项目> 做一次有边界的只读审计。

目标：<要解决的问题>。
已知现象：<发生时间、触发条件和已确认事实>。
本次范围：<可读取的目录、配置和相关日志窗口>。
预算与停止条件：<时间、样本或调用上限>。

先核对实际设备、工具能力和相关现行规范。按现象定位必要材料，不扫描全部个人文件，不输出凭据、客户正文或无关日志。

区分项目显示名称、项目归属、会话执行目录、磁盘文件夹和云端关联。将已验证事实、来源报告、推测和缺少的证据分开记录；不要把“没有找到记录”解释为“没有故障”。

本次不安装、不删除、不移动、不改权限、网络、电源或应用配置；不重启活动应用；不写原生数据库、运行缓存或会话文件；不新建后台任务或定时任务。

最后给出具体发现、依据、影响和最小的可恢复处理建议。每项建议说明需要改什么、如何验证、怎样恢复。证据不足或操作不稳定时，保留现状并说明缺口，不猜改设置。
```
