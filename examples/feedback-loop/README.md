# 反馈复用的虚构练习包

这是可运行的演示数据，不是已安装的 Codex 配置。全部文字重新编写，不代表真实项目、人员或验收记录。

初始状态包含一条现行规则和一条候选：简报基本结构已经采用，“单列未验证事项”还未采用。确认记录作为后续演示材料预先存在，候选起初不引用它。

从仓库根目录运行 `python3 -B tools/demo.py`。程序只把指定样例复制到自己的临时目录，模拟四种状态并检查结果；仓库内这个练习包保持原样。具体运行结果和边界见 [演示说明](../../docs/07-feedback-loop-demo.md)。

`registry.json` 分开记录反馈类别与生命周期，`ROUTING.md` 只列现行规则，`rules/` 保存正文，`evidence/` 保存虚构依据，`outputs/` 提供完整与缺章的成品样例。

两个输出的事实内容相同，差别在于是否把未验证事项放在独立标题下。检查器应报告结构差异，不能据此判断事实真伪或文档实际渲染效果。
