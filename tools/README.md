# 工具与隔离演示

三份检查器均使用 Python 标准库，需要 Python 3.9 或更高版本。它们不联网，不写源文件，不部署配置，不接触应用接口。另有一个只对自建临时目录写入的虚构演示。请只对你有权读取的、经过筛选的目录运行。

## 先运行反馈复用演示

```sh
python3 -B tools/demo.py
```

不接收参数。程序只读取仓库自带的虚构练习包，在自建临时目录中演示候选规则的采用与输出结构检查，结束后清理。预期为两个正常通过、两个指定失败；程序会断言具体问题代码。完整解释见 [演示说明](../docs/07-feedback-loop-demo.md)。

## 检查知识登记与输出结构

```sh
python3 -B tools/check_knowledge.py examples/feedback-loop
python3 -B tools/check_knowledge.py examples/feedback-loop --check-output outputs/complete.md
```

读取 `registry.json`、`ROUTING.md` 和明确引用的包内文件。检查候选／现行／停用、唯一 ID、同范围同主题的现行版本、采用依据、路由、替代关系及可选的必需标题。它不会自动采用规则，也不能证明依据真实、模型已读取或输出语义正确。

退出码 `0` 为本次结构检查通过，`1` 为规则或结构问题，`2` 为输入或读取错误。文件和语法上限、字段说明见 [演示说明](../docs/07-feedback-loop-demo.md)。

## 检查待公开文本

```sh
python3 -B tools/audit_public.py ./public-export
```

| 退出码 | 含义 |
| --- | --- |
| `0` | 本次文本检查未发现规则命中；仍需人工审阅 |
| `1` | 存在命中或不允许的文件／目录，需要处理 |
| `2` | 输入无效或检查未能正常完成 |

支持 Markdown、Python、JSON、YAML、TOML、TXT，以及少量仓库根文本文件。单文件上限为 2 MiB。二进制文件、软链接、部分隐藏和生成目录会被拒绝；`.git` 被明确跳过，因为这不是 Git 历史扫描器。

报告包含相对文件名、行号和规则名，不回显命中的正文值。**相对文件名本身仍可能敏感，报告应先在本地审阅。** 示例邮箱使用保留的 example 域名；示例之外的业务身份仍要人工检查。

尚未覆盖：所有自定义令牌、人名与客户关系、图片像素与元数据、完整 Git 对象和作者元数据、其他编码文件，以及检测期间并发写入造成的竞态。检查时应暂停对导出目录的编辑；它不是面向恶意文件系统的安全沙箱。

## 比较两份知识目录

先准备两个练习目录，各含 `standards/`、`templates/` 和 `ROUTING.md`，再运行：

```sh
python3 -B tools/compare_knowledge.py ./copy-a ./copy-b --include standards --include templates --include ROUTING.md
```

`--include` 可以重复。至少指定一项，只允许相对路径；不支持上级路径、隐藏路径和应用状态目录。不在白名单内的文件不会读取。选定路径中有软链接、非支持文本、编码问题、文件名大小写／Unicode 冲突，或单文件超过 4 MiB、累计超过 10,000 个文件时，会拒绝比较。

| 退出码 | 含义 |
| --- | --- |
| `0` | 至少有一个所选文件，且所选文件相同 |
| `1` | 存在内容不同、左侧独有或右侧独有的文件 |
| `2` | 比较被拒绝，包括没有选中文件；检查输入和边界，不要当作一致 |

报告字段：`different` 为同路径内容不同，`only_left`／`only_right` 为单侧存在，`matched_files` 为字节一致的文件数。Windows CRLF 与 LF、同义改写都会视为不同；这是有意保留的原始差异，不自动归一化或合并。

工具在本机读取两个目录，适合比较两个已取得的副本。它既不能证明副本来自哪个远端，也不会确认 Git 提交、同步服务、远端在线、模型读取或真实交付质量。它的文件名报告同样应留意隐私。

## 运行测试

在仓库根目录：

```sh
python3 -B -m unittest discover -s tests -v
```

测试仅使用临时生成的虚构文件，检查敏感标记不回显、软链接拒绝、白名单边界、文件差异和源文件不变。Windows 上创建软链接可能需要额外权限，因此该项测试会明确跳过，不要求修改系统权限来跑测试。
