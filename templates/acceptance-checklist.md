# 任务验收清单

按本次交付选择适用项。未执行的检查写明“未测试”及原因，不为了勾满清单扩大权限或重复测试。

## 目标与依据

- [ ] 交付物、适用对象和完成条件明确。
- [ ] 已读取相关现行规范，输入材料和版本可核对。
- [ ] 已区分已知事实、来源报告、推测和待确认事项。

## 修改与恢复

- [ ] 修改限于授权范围，已有用户修改得到保留。
- [ ] 配置变更有可用的恢复副本；没有变更则标记“不适用”。
- [ ] 未绕过应用入口改写原生数据库、运行缓存、会话或云端绑定。
- [ ] 没有新增无必要的定时任务、后台模型调用或常驻服务。

## 结果核验

- [ ] 文本和配置已检查格式、差异与必要链接。
- [ ] 行为变化已做与影响面相符的实际验证；静态检查没有被当作行为通过。
- [ ] 文件交付已按格式检查：需要时打开、渲染或在目标应用中核对。
- [ ] 失败、未覆盖范围和证据缺口已保留，没有写成“全面通过”。

## 跨设备任务

- [ ] 已核对发起设备和目标设备身份，没有把相对的 `local` 当成固定设备。
- [ ] 知识版本、项目归属、执行目录、会话历史和云端关联分别说明。
- [ ] 如声称远程任务成功，已有目标设备的实际执行结果及退出状态；发送成功不算执行成功。
- [ ] 已通过部分未无故重做，预算、计数和截止没有重置或延长。

## 经验与发布

- [ ] 仅把有复用价值且范围明确的反馈写回唯一来源，并已回读。
- [ ] 没有新经验时不创建空总结；候选方法没有升级为已验证规则。
- [ ] 公开材料已检查敏感正文、路径、附件、示例、截图及 Git 历史；扫描工具结果仍经过人工复核。
- [ ] 最终说明包含交付位置、验证边界、剩余事项和必要的用户操作。
