## 范围

| 项目 | 内容 |
| --- | --- |
| 主要任务 | <反复发生、需要集中复用的工作> |
| 不在范围内 | <容易混入但应单独处理的工作> |
| 主要交付物 | <文档、代码、配置或其他文件> |
| 当前工作目录 | <本机实际目录；多设备路径不同可分别记录> |
| 交付位置 | <相对路径或明确的输出位置> |

一个项目优先对应一个主工作目录。已有多目录项目先登记事实和依赖，不因整理外观迁移历史内容。侧边栏项目名、会话执行目录、磁盘文件夹和云端关联分别记录，不能互相代替。

## 开始一个任务

提供本次目标、输入材料、约束和新增信息。助手应读取相关入口，确认材料版本，并说明本次采用的验收方式。缺少会改变结果的关键资料时先指出，不凭旧聊天猜测。

## 结束一个任务

交付可直接使用的结果，并说明已检查的内容、尚未验证的部分和需要保留的恢复材料。有明确且可复用的新反馈时，按 [规则条目模板](./knowledge-entry.md) 更新唯一来源；没有就不新增总结文件。
